|----------------|--------------------------------------------|

| `CHAT_ID`      | `c0Cr7CY0d779b05feaf43526b36a6010`         |
| `CHANNEL_LINK` | `https://rubika.ir/giahanedaroi`           |

### ۲. فعال‌سازی Actions

- برو به تب **Actions**
- اگر پیغام داد که workflows رو فعال کن، تأیید کن.

### ۳. تست دستی

در تب Actions روی workflow «ارسال پست گیاهی هر ساعت» کلیک کن و **Run workflow** بزن.

## نکات مهم

- ربات باید در کانال **ادمین** باشد و دسترسی ارسال پیام داشته باشد.
- محتواها به صورت تصادفی از لیست انتخاب می‌شوند.
- می‌توانی محتوای بیشتری به فایل `bot.py` اضافه کنی.
